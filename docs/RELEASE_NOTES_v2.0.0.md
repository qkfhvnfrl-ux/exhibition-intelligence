# FIELDNOTE v2.0.0

FIELDNOTE의 정식 2.0 버전입니다. 지도에서 업체와 장비를 탐색하고, 사진·공식 자료와 전시회 종합보고를 확인할 수 있습니다.

**[공식 웹앱 열기](https://qkfhvnfrl-ux.github.io/exhibition-intelligence/)** · [업체 탐색](https://qkfhvnfrl-ux.github.io/exhibition-intelligence/#companies?event=adex-2025) · [종합보고](https://qkfhvnfrl-ux.github.io/exhibition-intelligence/#report?event=dsei-2025)

## 주요 변경

- 큰 지도 → 업체 메인 → 장비별 사진·설명 → 종합보고의 탐색 흐름과 제품별 직접 주소.
- 5개 전시회, 65개 장비 설명·325항목, 데스크톱 16:9·모바일 세로 종합보고 5종.
- 한화·경쟁사의 전차·장갑차·탑재장비 사례와 근거를 중심으로 종합보고 개편.
- 사진·참고이미지 보유 업체를 먼저 표시하고 공식 자료만 있는 업체를 다음으로 배치.
- 제조사 카탈로그·제품 자료 40개 URL, 그중 PDF 24개 연결. 정확한 장비 자료와 업체 공통자료를 구분.
- 최근 자료 보강에서 사진 11장·제조사 참고이미지 2개 추가. 표시 이미지 보유 업체는 전시회별 합계 45개, 정확한 제품 사진 연결은 40개.
- 현장사진·일반 참고사진·도해·발표문·공식 프로필을 구분하고 원문과 이용조건 제공.

## 공식 버전 관리

- 정식 버전은 기본 웹앱 주소와 GitHub의 최신 정식 릴리즈를 기준으로 합니다.
- 기존 `/preview/` 주소는 같은 정식 빌드를 제공하는 호환 주소입니다. 별도 미리보기 버전으로 관리하지 않습니다.
- `v2.0.0`부터 정식 버전 태그를 사용합니다. 기능 추가는 minor, 수정·자료 보강은 patch로 기록하며 공개한 태그를 이동하지 않습니다.
- 이전 `v2.0.0-preview.1`은 이력으로 보존합니다.

## 검증과 제한

정식 버전의 빌드와 전체 자동검사 230개를 통과했습니다. 배포 구성은 같은 버전·커밋의 루트/호환 주소, 개발 버전 배포 거부, 기존 산출물 덮어쓰기 거부를 검사했습니다. 공개 후 GitHub Actions·Pages 결과와 버전·배포 커밋 및 익명 HTTP를 확인합니다.

등록된 업체·제품 수는 실제 참가 또는 출품 확인 수가 아닙니다. 일부 업체·장비에는 사진이 없고 공식 프로필이나 근거 링크만 있습니다. 외부 자료는 제공 사이트의 접근 제한·변경 영향을 받을 수 있습니다. 새 종합보고 PDF 파일의 재생성과 실제 휴대폰 검증은 이번 정식 릴리즈에서 완료한 범위에 포함하지 않습니다.

첨부 웹앱 ZIP은 동일한 정적 빌드입니다. 압축을 푼 뒤 HTTP 서버에서 실행해야 하며, 외부 사진과 자료 원문은 인터넷 연결이 필요합니다.
