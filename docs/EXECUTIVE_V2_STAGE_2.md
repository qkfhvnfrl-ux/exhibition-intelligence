# 2단계 사용자 지시 원문

수신일: 2026-11-12 (Asia/Seoul). 아래 구분선 이후는 받은 요청 원문입니다.

---

exhibition-intelligence의 EXECUTIVE_V2_BRIEF.md와 작업상태를 읽고 2단계를 수행하세요.

5개 회차의 공식 참가업체 디렉터리·행사 가이드·팜플렛·배치도를 조사해, 관련 기업을 빠짐없이 검토할 모집단과 데이터 구조를 구축하세요. 유명 기업 검색부터 시작하지 말고 공식 명단의 페이지·알파벳·분류를 끝까지 확인하세요. 한 번에 많으면 행사별로 저장하고 미완료 범위를 남긴 뒤 다음 묶음을 이어가세요.

조사 출발점

- ADEX 2025: "BtoB 운영 페이지" (https://adex.bciaerospace.com/)와 "2025 배치도 PDF" (https://adex.bciaerospace.com/images/pdf/SEOUL_ADEX_FLOOR_PLAN_EN.pdf)
- Eurosatory 2026: "공식 Catalogue and map" (https://www.eurosatory.com/en/catalogue/)과 "Eurosatory LAB" (https://www.eurosatory.com/en/eurosatory-lab/)
- DSEI 2025: "공식 Exhibiting Companies" (https://www.dsei.co.uk/visit/exhibiting-companies)
- IDEX 2025: 주최사 2025 공식 디렉터리·행사 가이드를 우선 탐색. 보조 경로는 "BDSV의 IDEX 2025 명단" (https://bdsv-exhibitions.eu/idex-2025)
- SAHA 2026: "공식 Exhibitor List" (https://sahaexpo.com/en/exhibitors)

위 주소의 현재 내용과 회차를 다시 확인하세요. DSEI의 사이트 머리글이 2027이어도 해당 목록 본문은 2025인지 확인하고, IDEX의 현재 2027 배치도를 2025 지도에 사용하지 마세요. 국가관·협회·LAB 부분명단을 전체 명단으로 취급하지 마세요.

원장과 분류

- 공식 명단 원문·확보 날짜·수집 범위·누락 페이지를 기록하고, 업체별 ‘관련 확인 / 관련성 검토 중 / 제외 사유’를 남기세요. 작은 공용부품도 차량 적용과의 구체적 연결이 있으면 포함하세요.
- 업체, 브랜드·계열사, 유통사, 행사 참가, 부스, 제품, 현장사진, 카탈로그, 분석, 근거를 구분해 연결하세요.
- 기업과 행사 참가를 분리하고 기업↔부스는 다대다로 관리하세요. 공동관, 한 기업의 여러 부스, 동일 제품의 여러 사진을 중복 기업으로 집계하지 마세요.
- 명단 등재·참가 예정·현장 참가 확인을 구분하고, 특정 제품의 전시 확인, 부스번호 확인, 지도 좌표 확인도 별도 상태로 관리하세요.
- 기본정보 등록과 심층분석 완료를 구분하세요. 심층분석 완료는 실제 전시 근거에 연결된 출품 내용·업체 고유의 판단·당사 업무 연결·근거 링크가 검토된 경우입니다. 회사소개만 있는 기업은 심층분석 완료로 집계하지 마세요.
- 모집단 확보 수, 중복 제거 업체 수, 관련성 검토 완료 수, 관련 업체 수, 심층분석 완료 수, 지도 연결 수, 자료 부족 수를 구분하세요. 전체 모집단을 확보하지 못하면 전체 대비 완료율을 계산하지 마세요.

지도 원본

행사·회차·개최장소·홀/층/야외구역·문서 페이지·원문 URL·발행/개정일·원본 크기·회전/크롭 정보를 기록하세요.

공식 사전 배치도는 당일 실측 배치라고 단정하지 말고, 당일 사진이나 수정 공지가 있으면 대조하세요.

부스 사각형/다각형은 지도 원본에 연결한 정규화 좌표로 저장하고 OCR 결과는 원본 확대 이미지 및 업체 부스번호와 재검토하세요. 부스번호만 확인됐으면 좌표를 임의로 채우지 마세요.

자료 이용 조건을 확인해 사용 가능한 원본은 저장하고 나머지는 출처 연결로 처리하세요.

실제 작업과 완료 조건

실제 데이터 파일·수집 원장·유효성 검사까지 작성하세요. 기존 데이터도 새 구조에 매핑하고 안정적인 ID를 유지하세요. 출처가 다른 사실·관찰·해석을 데이터에서 구분하되 조사 관리 항목을 임원 화면에 노출하지 마세요.

이 단계는 5개 행사의 자료 확보 상태·수집 범위와 공통 데이터 구조·기존 자료 이전·ADEX 지도 구현용 검증 업체/부스 자료까지 준비하면 완료입니다.

남은 전체 명단 수집·관련성 판정·심층분석은 4~8단계 작업 큐에 연결하세요. 접근불가·부분명단·미착수를 구분하고, 미완료 범위와 다음 작업이 명확하면 3단계 구현으로 진행하세요.
