## 파이프라인 검토

확인한 보호 장치: 미확인 좌표 생성 금지, 부스번호와 지도 도형 분리, PEI 번호 충돌을 별도 정정 없이 확정하지 않음, 행사 회차가 다른 출품 근거 거절, 일반 제품자료의 실제 출품 개체 제외, 명시적으로 조사한 자료부족과 미착수 구분, 전체 모집단 미확보 시 완료율 null, 링크 전용 사진의 직접 이미지 표시 금지, 일반 화면에 조사 큐·완료율을 배포하지 않음.

완료 업체 수는 전체 제품 실물·성능 검증 수가 아닙니다. 이번 범위의 근거 있는 업체 분석 종료 여부이며, 개별 발표 품목의 미확인 조건을 보존해야 합니다. 사전 발표만 있는 업체를 실제 출품 확인 또는 분석완료로 자동 승격하면 안 됩니다.
