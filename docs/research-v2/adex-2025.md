## 수집 단위와 수량의 의미

유명기업 검색으로 모집단을 만들지 않았다. 확보한 공식 지도 1쪽의 Hall 7 → 8 → 9 → 10에서 작은 그리드와 큰 블록을 빠짐없이 훑고, 시설 표기를 제외한 명칭 관찰행을 만들었다.

| 단위 | 원문 명칭 관찰행 | 확대 검토 범위 |
| --- | ---: | --- |
| Hall 7 | 122 | 큰 블록과 별도 확대 구역은 검토. 작은 밀집 글자는 행별 상태에 따라 추가 확인 필요. |
| Hall 8 | 157 | 큰 블록 검토. 작은 밀집 글자는 개별 확대·신원 확인 대기. |
| Hall 9 | 36 | 전체 명칭 확대 확인. 반복 블록과 공동명칭을 그대로 유지. |
| Hall 10 | 47 | 전체 명칭 확대 확인. NINANO·Korean Air·현대차그룹·LIG 반복 블록 유지. |
| 합계 | **362** | `visually_reviewed` 148행, `needs_review` 214행. |

대소문자만 정규화한 서로 다른 원문 명칭은 **355개**다. 이 수치는 중복 제거 기업 수가 아니다. 기관·협회·국가관·언론·공동 표기와 미확인 후보 철자가 포함되어 있다. 네 홀 스캔 완료와 개별 명칭의 확정 정확도를 구분한다. `needs_review` 행의 근거는 확정 사실이 아닌 관찰로 저장한다.

공동관 내부 기업, 야외/별도 정적 전시, 최종 디렉터리의 추가 참가기업이 확보되지 않았다. `expectedTotal=null`, `complete=false`, 전체 대비 완료율 없음이 정확한 상태다. 362행은 이 부분 모집단의 수집량이다.

카페·세미나실·기자회견실·화장실·대표단 라운지·BtoB·기도실·USA Pavilion Meeting Point 같은 시설명은 기업행에서 제외했다. 기관/협회/국가관은 빠짐없이 남겨 구성원 확장 대상으로 표시했다. 기관이나 항공 관련 이름만으로 차량 관련성을 배제하지 않았다.

## 식별·공동 블록·확인 상태

- `id`는 홀·원문 명칭·동일 명칭의 출현 차수를 해시한 관찰 ID다. 순서가 바뀌어도 식별자를 유지한다. 법인 ID가 아니다.
- 지도 같은 이름의 두 물리 블록은 두 관찰행이다. 기업 수 집계에서 두 기업으로 세지 않는다.
- 현대그룹 3개사, 한화 4개사, SNT 2개사는 원문 명시 이름만 `listedOrganizations`에 분리한다. 한화 공동 블록 자체를 새 법인으로 만들지 않는다.
- `Seedcore Abaco Systems`, `KYEONG IN TECH KAES`, `Click Bond A-Tech Aviation` 등은 유통사/브랜드/공동출전 관계가 미확인이다. `organization_unresolved`와 원문을 유지하며 임의 병합·분리하지 않는다.
- 361행의 관련성은 검토 중, PEI-GENESIS 1행만 구체적 커넥터/배선 인터페이스 연결을 기록했다. 심층분석 완료는 0이다.
- 지도만으로 현장 참가·특정 제품 출품을 확정하지 않았다. 모든 관찰의 `participationStatus=listed`다.

PEI-GENESIS는 [업체의 2025-10-02 발표](https://www.prnewswire.com/apac/news-releases/pei-genesis-to-exhibit-at-seoul-adex-2025-in-korea-302572565.html)에서 Hall 7, booth 18-20 참가 계획을 확인했다. 지도상 이름/위치와 별도 교차대조가 가능하지만 **부스번호의 근거는 업체 발표 한 개**다. PR Newswire는 배포사이며 독립 보도 두 번째 근거가 아니다. 군용 원형·RF·광 커넥터와 케이블 어셈블리의 계획을 차량 배선/임무장비 인터페이스 검토로 연결한 판단을 해석으로 구분했다. 실제 현장 출품·차량 적용은 미확인이다.

텍스트 추출 결과는 빈 페이지 구분자뿐이었다. 전체를 9000 × 6365px로 렌더링하고 홀별 잘라낸 확대 이미지와 OCR를 대조했다. OCR를 확정값으로 자동 수입하지 않았다. 예를 들어 작은 문자에서 혼동되던 BRITESTONE, SCD, CzechTrade를 원본 확대 기준으로 다시 읽었다. 확정하지 못한 밀집 명칭은 개별 재검토 큐로 남겼다. 조사용 크롭은 좌표 데이터가 아니며 정규화 지도 좌표는 별도 검증 파일에서만 관리한다.

운영 페이지와 SIBAT는 권리 유보 표기가 있다. 공개 열람만으로 복제 허용을 인정하지 않는다. 배치도/HTML/PDF 원본은 조사 scratch에만 확보했고 저장소에는 사실 명칭·URL·확보시점·체크섬·회차판정만 남겼다. 모든 출처의 `rights.status=link_only`. 공개 배포 자산으로 지도 원본을 복제하지 않았다. 이용 허락/공식 임베드 범위 확인은 다음 단계의 외부 연결 구현 조건이다.

재생성/검사:

```sh
python scripts/collect-adex-2025.py
python scripts/collect-adex-2025.py --check
# 재확보 PDF의 동일 개정 여부까지 검사할 때
python scripts/collect-adex-2025.py --pdf /path/to/SEOUL_ADEX_FLOOR_PLAN_EN.pdf --check
```

스크립트는 안정적 ID 유일성, PEI 이외 부스번호 없음, 다른 행의 관련성 미확정, 모집단 미완료·전체 분모 미상 및 생성물 일치를 검사한다. 이는 출품 사실 독립 검증을 대체하지 않는다.

## 4단계 정확한 재시작점

1. `queue-adex-2025-full-directory`: 공식 exhibitor-list/downloads 재접속 또는 공식 2025 앱·보관된 디렉터리 확보. 페이지·알파벳·분류 끝까지 순회하고 원문 수/누락 범위를 기록한다. 2027 Sourcehere 및 2023 SIBAT PDF를 2025로 수입하지 않는다.
2. `queue-adex-2025-pavilions`: 국가·지역·협회·New Technology 공동관 내부 전체 명단을 2025 하위 원장으로 펼치고 기존 지도행과 연결한다.
3. `queue-adex-2025-identity`: `transcriptionStatus=needs_review` 214행을 한 번에 홀/구역 묶음으로 확대 확인한다. 후보 철자·기관·계열사·브랜드·유통사 관계를 구분해 기업 ID로 정규화하고 관련성을 전수 판정한다.
4. `queue-adex-2025-onsite`: 최종 지도 수정, 당일 부스사진, 실출품 자료·카탈로그를 대조한다. 계획·목록 등재·현장 참가·제품 전시·부스번호·좌표를 각각 승격하며 출처 하나만 있는 핵심 주장은 단일 근거를 유지한다.

이 미완료 목록은 3단계 구현을 막는 전체 디렉터리 완성 요구가 아니다. 공식 실내 지도와 검증된 일부 지역/업체 연결을 사용하는 구현에 진행할 수 있으며 후보 명칭·조사 관리 원장은 임원 화면의 완료 주장으로 노출하지 않는다.
