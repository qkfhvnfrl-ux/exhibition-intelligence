## 파일 검증 결과

2026-11-11, Python으로 실제 JSON을 읽어 다음을 확인했습니다.

- 사례 5개, 원문 근거 레코드 13개. 원문 레코드 수는 독립 검증 수가 아닙니다.
- 모든 조직·제품 ID가 `registry.json`에 존재합니다. 제품 ID 연결은 기존 7개를 유지합니다.
- 사례별 첫 화면 핵심 항목 3개와 후속 확인 3개가 있습니다.
- 분류 ID는 공통 15개 분류에 포함되고, 모든 하위 `sourceIds`가 해당 사례의 근거 ID를 참조합니다.
- 재사용 사진 7개는 기존 사진 ID·경로와 일치하고 파일이 존재합니다.
- `link-only` 사진에는 `src`나 직접 이미지 URL이 없습니다.
- JSON 파싱·내부 참조 검증은 통과했습니다. UI 동작·빌드·모바일 검증은 이 조사 파일의 검증 범위가 아니며 다른 단계 작업 결과에 따릅니다.

## 4단계로 넘기는 조사 큐

1. 원문 근거가 있는 나머지 ADEX 명단에 같은 구조를 확대합니다. VITZROCELL 등 작은 전력·부품 기업은 실제 회차 자료를 찾기 전 일반 제품 소개만으로 사례 완료 처리하지 않습니다.
2. 현대로템 차륜 계열의 개별 실차/모형, STX 모델별 실제 형식, PEI 개별 품번과 원제조사·유통·조립 역할을 확인합니다.
3. STX·PEI 추가 각도 사진과 원문 카탈로그의 허용 범위를 확보합니다. EDR 원문 접근이 가능해지면 본문·사진을 재대조합니다.
4. PEI 부스번호 상충은 공식 수정 배치도·번호 표지 사진 등 별도 근거를 찾아 해결합니다. 확인 전 좌표를 만들어 채우지 않습니다.
5. 비교 시험 조건이 없는 품목은 비교 불가 상태를 유지합니다. 전시 발표를 성능 검증이나 당사 채택·협력 사실로 바꾸지 않습니다.
