## BDSV 명단을 끝까지 확인한 방법

유명 업체부터 찾지 않고 `All` 화면을 내려받아 HTML의 모든 `exhibitor-data` 구간을 순서대로 추출했습니다. 0–9와 A–Z의 27개 구분을 모두 대조했습니다. All 화면에는 30개 고유 프로필이 있으며 별도 next/pagination 요소는 없습니다. 각 알파벳 필터의 활성/비활성 상태가 추출 행의 첫 글자 분포와 일치합니다. 필터마다 별도 POST 요청을 보냈다고 주장하지 않습니다.

| 구분 | 추출 행 수 |
| --- | ---: |
| 0–9 | 0 |
| A / B / C / D / E / F | 2 / 1 / 0 / 4 / 1 / 0 |
| G / H / I / J / K / L | 1 / 3 / 1 / 0 / 3 / 1 |
| M / N / O / P / Q / R | 0 / 0 / 1 / 1 / 1 / 4 |
| S / T / U / V / W / X / Y / Z | 5 / 1 / 0 / 0 / 0 / 0 / 0 / 0 |
| 합계 | 30 |

첫 행은 Argus Interception GmbH, 마지막 행은 TARGUS Management Consulting AG입니다. 웹 텍스트로 표시된 30개 프로필·부스 목록과 원본 HTML의 30개 행을 대조했습니다. 이는 **같은 자료를 두 방식으로 추출한 검증**이며 독립된 두 출처로 참가·제품을 검증한 것은 아닙니다.

재현 명령:

```sh
python scripts/collect-idex-bdsv.py /path/to/downloaded-bdsv-idex-2025.html
```

스크립트는 외부 패키지가 필요 없고, 회차 제목·프로필 경로·누락 행·중복 ID·알파벳 제어·페이지 나눔을 검사합니다. 업체 설명·로고는 출력하지 않습니다. 확보한 HTML의 SHA-256은 원장과 근거 JSON에 기록했습니다. HTML에는 세션 토큰이 포함되므로 재요청 파일의 바이트 해시가 달라질 수 있습니다. 단순 해시 차이를 명단 변경으로 간주하지 말고 추출된 행과 프로필 ID를 비교합니다.

## 7단계에 이어갈 정확한 범위

1. 주최사 또는 공식 출판사 Event Guides의 실제 **2025** 전체 디렉터리·Event Guide·Pocket Map 확보. 원래 페이지/알파벳/국가관/분류 구간을 확정하고 누락 없이 순회합니다. 현재 전체 페이지 수가 확인되지 않아 특정 미확인 페이지 번호를 발명하지 않았습니다.
2. BDSV 외 전체 기업과 공동관·하위 브랜드를 원장에 추가합니다. BDSV 내부의 누락 페이지는 발견되지 않았으나, BDSV 자체가 전체 행사에 대한 부분명단입니다.
3. 현재 20개 보류 행 및 추가 모집단의 관련성을 하나씩 검토하고 10개 관련 확인의 구체적인 차량 연결을 독립 자료로 재대조합니다.
4. 실제 2025 출품·현장사진·제품·카탈로그·부스 근거를 분리해 연결하고, 업체 고유 판단과 당사 업무 연결까지 검토한 경우에만 심층분석 완료로 전환합니다.
5. 실제 2025 지도 원본을 확보한 뒤 부스번호와 확대 원본을 대조합니다. 2027 지도와 주차 안내는 좌표 원본으로 쓰지 않습니다.

이 미완료 범위는 원장의 4개 `queues`에 7단계 작업으로 연결했습니다. IDEX 전체 원장 미확보가 3단계 공통 화면 구현을 막지 않도록 데이터 상태를 명시했습니다.
