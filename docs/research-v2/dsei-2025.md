# DSEI 2025 공식 모집단 수집 원장

확인일: 2026-11-11 UTC. 데이터: `data/v2/collection/dsei-2025.json`.

## 확보 범위와 회차

[공식 Exhibiting Companies](https://www.dsei.co.uk/visit/exhibiting-companies)의 **현재 공개된 2025 본문 전체 페이지**를 수집했다. 페이지 머리글 로고는 2027이지만 8페이지의 본문 H1은 모두 `2025 Exhibiting Companies`다. 공식 [2025 도움말](https://dsei25.freshdesk.com/support/solutions/articles/79000147177-why-can-t-i-receive-a-pdf-of-the-attendees-or-exhibitors-at-dsei-)도 공개 웹 명단과 로그인 전용 상세 자원을 구분한다. 이 도움말은 2025-09-05 수정 표기가 있다.

전체 알파벳 상태의 공식 페이지네이션을 따라 1~8페이지를 확보했다. 1페이지의 Last Page 링크는 8을 가리키며 마지막 페이지에는 Next Page가 없다. 회사 검색이나 국가관 필터로 모집단을 구성하지 않았다.

## 데이터와 검증

- 공식 `data-content-i-d` 1,754개 모두 고유하다. 이를 안정 ID로 사용하고 원문 이름·원문 부스문구·프로필 URL·페이지/행 위치를 남겼다.
- 1,753행에 부스가 기재되어 있다. 부스 연결은 1,755건, 고유 부스코드는 1,034개다. 공동관이나 같은 부스가 같은 기업이라는 뜻은 아니다.
- `The NAD Group`은 C-10 / S14-220 / S14-230을 가진다. `Chrosziel`의 한 원문 행은 부스가 없다. 빈 부스를 보충하지 않았다.
- 동일 원문 이름이 15쌍 있다. 서로 다른 공식 ID를 유지했다. 이들을 업체로 통합할지는 법인·브랜드·지사·참가 관계를 확인한 뒤 결정한다. 같은 이름이라는 이유만으로 삭제하지 않았다.
- 공식 필터의 분류 421개와 국가 50개를 저장했다. 이 필터는 업체별 분류 근거가 아니므로 개별 행에 자동 부여하지 않았다.
- 첫 검증: DOM으로 8개 페이지 제목, 명단 카드, 페이지 이동, 마지막 페이지를 검사했다.
- 두 번째 검증: 원문 바이트의 카드 ID를 정규식으로 독립 집계해 DOM 개수와 대조했다. 원문 SHA-256과 저장된 해시, ID 중복, 페이지 연속성도 검사했다.
- 출처는 공식 디렉터리 단일 계열이다. 여러 페이지나 도움말은 개별 참가 사실의 독립 검증이 아니다. 모든 행은 `listed`, 관련성은 `pending`, 제품/현장사진/좌표/심층분석 완료는 0이다.

## 재수집 방법과 이용 조건

`scripts/collect-dsei-2025.py`는 Python 3와 lxml로 실행한다. `--fetch`를 주면 공식 Last Page를 확인한 뒤 공개 페이지만 순서대로 요청한다. 원문 HTML은 저장소 밖 cache에만 저장하고, 저장소에는 사실 식별자·해시·출처·수집 범위를 남긴다.

```sh
python scripts/collect-dsei-2025.py --cache /tmp/dsei-2025 --fetch
```

이번 검사에서 공개 페이지/푸터의 재사용 허가를 확인하지 못했다. 로고·사진·설명문·전체 HTML의 재배포 허가를 추정하지 않고 `link_only`로 기록했다. 로그인 전용 자료를 접근하거나 우회하지 않았다.

## 가이드·지도 상태와 6단계 시작점

[공식 2025 Post Event Report 소개](https://www.dsei.co.uk/about/2025-post-event-report)는 확인했다. Download 링크는 웹 접근에서 현재 홈페이지로 이동했으며 원본 보고서/2025 행사 가이드/부스 배치도는 확보하지 못했다. 현재 2027 자료를 2025 지도에 사용하지 않았다. 좌표는 모두 비어 있다.

6단계는 JSON의 `q-dsei-2025-relevance`에서 1페이지 첫 행부터 8페이지 마지막 행까지 업체별 관련성을 검토한다. 공통부품·제조·시험 기업도 빠짐없이 유지한다. `q-dsei-2025-map`은 공식 2025 가이드/배치도 원본과 이용조건 확보부터, `q-dsei-2025-depth`는 해당 회차 제품·사진·현장참가 근거부터 시작한다. 부족 자료 때문에 다른 기업 검토를 멈추지 않는다.
