# 개편 콘텐츠 근거 보강 계획

기준일: 2026-11-15 (Asia/Seoul). 시작 커밋 a21b781.

## 입력·현재 상태

최종 목표는 의사결정용 기존 보고서를 대체할 사진·설명·근거·가독성이다. A단계 초안과 감사는 저장되어 있으나 화면 방향/첫 공개 범위 결정은 미수신이다. 이전 목표 턴은 초안·QA·감사 커밋을 남긴 progress로 분류한다. 현재 작업 트리는 clean이다.

## 목표

이미 승인된 조사·검증 범위에서 ADEX 2025 현대로템·현대위아·기아의 장비별 설명 근거를 보강하고, 같은 전시회 2023 회차와 비교 가능한 사실을 분리한다. 3사 표본을 전체 행사 조사 완료로 대체하지 않는다.

## 수정 파일

- docs/research-v2/redesign-content-*.json 또는 .md: 출처·주장·사진 식별·이용조건·검증 수준과 누락 기록.
- docs/evidence/REDESIGN_CONTENT_*.json: 원문·자산 응답/대조 결과.
- PROJECT_STATE.md, TASKS.md, DECISIONS.md, EVIDENCE.md, CHANGELOG.md, HANDOFF/STATUS: 실제 진행 범위.

## 영향 범위

조사 증거와 후속 편집용 콘텐츠 초안만 변경한다. 제품 src/data 스키마·빌드·라이브러리·배포·사용자 기록은 변경하지 않는다. 이번 조사 기록은 아직 화면에 반영한 제품 설명으로 집계하지 않는다.

## 리스크

- 2023 소개와 2025 소개를 성능 향상/최초 출품으로 과장할 위험.
- 현장사진 속 모형·실물·형상과 기사 일반제품 내용을 혼동할 위험.
- 제조사 기사 하나의 재전재를 독립 자료로 중복 계산할 위험.
- 사진 이용 안내의 제3자 권리 예외와 제공기관/촬영자 구분 누락.

## 검증 방법

1. 제조사·주최사 원문을 열고 회차·날짜·제품 문장을 직접 확인한다.
2. 비교 문장은 같은 업체/제품의 2023·2025 원문으로 대조한다. 독립 근거 부족은 표시한다.
3. 사진 파일은 이미지 응답, 해시/치수, 원문 캡션/제공기관/조건을 연결한다. 읽을 수 없는 사진을 검증 완료로 세지 않는다.
4. 출품 근거와 일반 제원 근거, 공식 계획과 관찰 추론을 분리한다. 내부 업무 연결 내용은 작성하지 않는다.
5. JSON 파싱·필수 필드·링크/자산 파일 존재를 검증한다. 제품 코드 무변경이면 기존 build/test를 불필요하게 반복하지 않는다.
