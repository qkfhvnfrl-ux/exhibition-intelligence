## 최초 지적과 재검증

| 지적 | 수정 후 확인 결과 |

기업·행사 참가·부스와 점유 연결은 별도 테이블이다. 공동관과 복수 부스를 다대다로 표현하며, 명단 행 수·조직 라벨 수·업체명 후보 수·관련성 검토·심층분석·지도 및 번호 연결 수를 분리한다. 모든 행사의 전체 모집단 완료율은 현재 `null`이다.

## 공개 데이터와 해석 조건

- 공개 분석에서 수집 원장, 작업 큐, 진행률, 관련성 작업상태, 완료 상태, 검토 상태, 원문 처리 위치, 이전용 원본 객체를 제외한 것을 재귀 검사로 확인했다.
- 분석 62건과 연결 주장 549건은 공개 투영에 남는다. 모든 기존 분석에 회차별 출품 근거·수치 재대조가 완료되지 않았다는 해석 조건이 있다. 수치·범위 등의 조건 182건과 사실·관찰·해석 구분, 출처 링크를 유지한다.
- 공개 주장 426건에 `evidenceStatus=single_source`가 남는다. 다른 자료에서 나온 링크 수만으로 독립 검증을 주장하지 않는다.
- PEI 부스의 `numberEvidence`는 단일 원문 출처와 발표 조건을 연결한다. 공개 출처에는 발행사·제목·발행일이 남고, 사전 배치도는 `pre_event_plan` 상태를 유지한다.
- ADEX 전사 재확인 필요 원행 214건은 반복 명칭을 합친 참가 213건의 `sourceLabelStatus=needs_review`로 공개 데이터에 남는다. 이는 관리 진행률이 아니라 표시 이름의 불확실성이다.
- 원본 지도 이용조건 `link_only`를 유지하고 복사·임베드 허가를 주장하지 않는다. 원본 크기를 확보하지 못한 Eurosatory 안내도는 좌표 없는 문서로 보존한다.
