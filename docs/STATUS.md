# 진행 상태

Version: **1.1.0** · 2026-11-11

## 이번 변경

보고 화면을 실제 전시 장비·현장사진·짧은 개발전략 요약 중심으로 바꿨습니다. 장비별 사실·해석·확인 패널을 보고의 중심에서 빼고 1~2문장 개발전략과 핵심 전시 특징으로 정리했습니다. 출처는 펼쳐서 확인할 수 있습니다.

분석 기간은 **2024-11-11~2026-11-11**입니다. 최신 보고에는 이 기간에 열린 5개 행사만 포함하고, 다른 행사·훈련·기존형 참고사진은 보관함으로 분리했습니다. 직전 회차 자료를 새 보고에 일반 참고사진으로 섞지 않습니다.

이는 **1차 수집 완료분**이며 전수 조사 완료를 뜻하지 않습니다. 장비 사례 수에는 계열·공동 전시 묶음이 포함됩니다.

- ADEX 7장에는 부스 전경 1장이 포함되며 개별 장비 분석사진과 구분됩니다.
- IDEX 14장 중 유사 연속촬영 2장은 같은 방향 사진으로 표시하고 기본 보고서에서 제외합니다.
- SAHA는 4개 장비 사례와 사진 메타데이터 9건을 원문 5개에 연결했습니다. 표시 가능한 사진은 0장으로 명시하며 추가 재사용·임베드 조건 확인이 필요합니다.
- 전체 사진 원문 페이지 10개는 중복을 제외한 수입니다. 추가 갤러리 링크 및 그 안의 미검토 사진은 표시 사진 수와 별도입니다.
- Flickr 20장은 외부 제공 이미지로 연결하며 원본 파일을 공개 저장소에 복제하지 않았습니다.

## 구현 범위

1. 5개 행사 종합·개별 보고와 장비별 개발전략 요약.
2. 해당 회차 현장사진의 검색·필터·확대·2장 비교.
3. 출처·촬영자·날짜·현장 식별·이용조건과 원문 연결.
4. 전체 또는 선택 행사의 보고서·브라우저 인쇄/PDF 저장.
5. 이전 메모·주석·상태·확정본을 보관함에서 유지.
6. 개인 현장사진의 묶음 등록·분류·메모·브라우저 보존·사진 포함 백업·복원 유지.

개발전략은 전시 내용을 요약한 분석 의견이며 업체의 공식 선언·기술 인증·결재 결과가 아닙니다. 개인 기록은 현재 브라우저에만 저장됩니다.

## 검증

- `npm run check`: 기존 49개 + 새 보고 UI 8개 + 행사 데이터 4개 = **61개 통과**. `npm run build` 및 `git diff --check` 통과.
- 브라우저에서 종합 보고 화면, DSEI 필터, DSEI 현장사진 6장 표시와 사진 2장 비교를 확인했습니다.
- Eurosatory 보고의 현장사진 22장이 모두 정상 로딩됐습니다. DSEI 보고는 사진 준비 완료 후 인쇄 호출까지 확인했습니다.
- 이전 버전에서 현장사진 등록·새로고침 후 보존·메모 수정·사진 포함 백업·해시 일치·중복 복원을 확인했으며 관련 회귀검사를 유지합니다.
- **실제 PDF 전체 페이지 나눔과 모바일 실기기 검수는 미완료**입니다. 반응형 스타일·자동검사는 실기기 검수를 대신하지 않습니다.
- 자료 구조 검증은 장비 성능의 독립 검증을 뜻하지 않습니다.
