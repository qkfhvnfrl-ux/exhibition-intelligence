# 진행 상태

Version: **1.0.0** · 2026-11-11

## 완료 범위

공개자료 분석과 개인 현장기록을 위한 1.0 구현·검증·공개 배포를 완료했습니다. 기존 공개 주소를 유지합니다.

- ADEX 2025 우선 사례: K2PL, 경량화 105mm 자주포, 전술차량용 RCWS.
- 상세 검토: 사진 11장(ADEX 2025 실제 현장 3장 + 참고 8장), 사진 관찰 연결 9개.
- 통합 갤러리: 장비 16종, 사진 60장. 기존 53장 + 상세 11장 − 중복 K2 참고사진 4장.
- 5개 전시회·14종 장비의 기존 자료실과 이전 개인 작업 유지.

## 구현 기능

1. 핵심 보고·전시회 분석·장비 상세·사진 비교·기술동향과 검토과제.
2. 전시회·연도·장비·분류·분석 주제·현장/참고 구분 필터, 사진 확대와 2장 비교. 같은 장비의 다른 사진도 비교 가능.
3. 사진 관찰 지점·개인 위치 주석·공개 사실·해석·확인 과제·원문 출처 연결.
4. 개인 메모·검토 상태·비교 사진 선택 저장, JSON 백업·복원, 수정본과 확정본.
5. 여러 현장사진의 묶음 등록, 업체·제품·전시회·연도·주제별 분류, 메모 수정, 검색·필터·삭제.
6. 사진 내용 해시를 이용한 동일 원본 중복 방지, 형식·용량 검사, 파일별 실패 안내.
7. 현장사진의 브라우저 저장과 재접속 복원, 사진 포함 백업·가져오기.
8. 선택 검토와 현재 현장사진 결과의 인쇄/PDF 저장. 출력 전 이미지 로딩 확인.
9. 저장 실패를 성공으로 표시하던 문제, 재접속 시 150개 초과 주석 삭제, 장비 목록 변경 시 과거 확정본 불러오기 실패 수정.

확정본은 자료·검토 내용의 저장본이며 기술 인증·결재 완료를 의미하지 않습니다. 개인 기록은 현재 브라우저에만 저장되고 서버로 전송되지 않습니다.

## 검증

- 최종 데이터 기준 `npm run check`: **49개 검사 통과**.
- `npm run build`: 통과.
- 브라우저 확인: 통합 갤러리 필터, 같은 장비 사진 2장 비교.
- 현장기록 확인: 실제 사진 1장 등록, 새로고침 후 보존, 메모 수정, 사진 포함 JSON 백업 다운로드와 원본 바이트 해시 일치. 같은 백업을 가져왔을 때 신규 0장·기존 1장 유지로 중복 제외를 확인했습니다.
- 보고 버튼은 사진 준비 완료 후 인쇄 호출까지 확인했습니다.
- 기존 상세 검토의 실제 사진·관찰 연결·주석·메모/상태·비교 선택·확정본 동작 확인.
- 자동검사: 자료·파일 연결, 상태 보존, 잘못된 백업 거부, 좌표·사진 참조 검증, 저장 실패 표시, 주석 제한, 비교 선택의 보고 반영, 이미지 로딩 실패 시 인쇄 중지.
- **실제 PDF 전체 페이지 나눔 및 모바일 실기기 검수는 미완료**입니다. 반응형 스타일 구현과 자동검사는 실기기 검수를 대신하지 않습니다.
- 데이터 구조 검증은 공개 제원의 독립 성능 검증을 의미하지 않습니다.

## 자료 한계

- ADEX 2025 현장사진은 장비당 1장입니다. 추가 8장은 기존 K2 형상 또는 2026년 다른 전시회의 참고자료입니다.
- K2PL 현장사진은 전면 일부가 다른 전시물에 가려져 있습니다. RCWS의 후속 사진은 인물·전시물로 가려진 일부 장비와 부스 맥락을 보여줍니다.
- 현장사진의 장비 존재와 제조사 설명을 연결하되, 치수·성능·양산·배치 완료를 사진만으로 단정하지 않습니다.
- 동일 출품 형상의 다각도·내부·부위별 사진은 장비별로 더 확보해야 합니다.
- 보고서의 긴 메모·주석은 기본 보고 섹션보다 많은 실제 PDF 페이지를 만들 수 있습니다.
