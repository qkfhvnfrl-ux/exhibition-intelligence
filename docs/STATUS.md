# 진행 상태

Version: 0.1.0

- 별도 앱. 5개 전시회, 지상장비 우선. 직전 회차는 동향 비교 근거만 수록.
- GitHub 저장 및 버전관리 승인. 사이트 공개 배포는 아직 요청되지 않음.
- 첫 실행 가능 버전 구현·검증 완료. 이 문서는 각 커밋에서 갱신.

## 저장된 구현
- 6개 주요 화면과 평가항목 편집·JSON 백업 화면.
- 14개 장비 / 53장 사진 / 71개 제원 / 98개 분석 / 본문 출처 48건.
- 사진 확대·2장 비교, 장비 2~4종 비교, CSV, 보고서 구성, 브라우저 인쇄/PDF.
- 공개자료와 재사용 권리가 확인된 사진만 저장. 개인 작업은 브라우저에 저장.

## 검증
- `npm run build`, `npm run check`: 10개 테스트 통과.
- 브라우저: 종합 현황, 장비 검색, 상세 사진·이동·확대·2장 비교, 장비 비교표, 보고서 생성, 보고서 선택 유지, 평가항목 이름 저장·복원 확인.
- 주요 화면의 이미지 로딩 오류 0건. 인쇄 스타일 포함; 실제 PDF의 전체 장비별 페이지 나눔은 후속 검수 대상.
- 14개 장비의 전시 근거와 주요 제원을 별도 재검토. 데이터 구조 검증은 원자료의 독립 시험 검증을 뜻하지 않음.
