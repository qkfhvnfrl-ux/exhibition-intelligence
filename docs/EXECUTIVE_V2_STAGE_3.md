저장소의 공통 지시와 작업상태를 읽고 3단계를 실제 구현하세요.

ADEX 2025를 첫 작동 사례로 사용하고, 같은 구조를 다른 전시회에도 재사용할 수 있게 만드세요. ADEX 원본을 현재 환경에서 검증할 수 없다면 검증된 다른 대상 회차를 우선 구현하고 ADEX는 미완료 큐에 남기세요.

첫 화면

상단에 전시회·회차 선택, 업체/제품 검색, 기술분류 필터를 두고 화면의 중심을 전시장 지도에 배정하세요.

확인된 공식 배치도 위에서 확대·축소·이동, 홀·층·야외구역 전환, 업체 검색 후 해당 부스 이동, 부스 클릭 후 분석 패널 열기가 실제로 작동해야 합니다.

공동부스는 연결된 업체를 선택하게 하고, 좌표 미확인 업체는 목록에서 찾을 수 있게 하되 지도에 임의 배치하지 마세요. 지도 이동·검색·업체 선택 상태를 뒤로가기와 직접 링크에서도 유지하세요.

둘러보는 경험

공식 배치도와 부스 바닥면을 이용해 2D 지도와 간단한 입체보기를 전환할 수 있게 하세요.

입체보기는 확인된 평면 위치를 낮은 부스 블록으로 표현하고, 클릭하면 자연스럽게 시점이 이동하면서 실제 부스사진과 업체 분석을 보여주세요.

실제 외관·높이·장비 배치를 모르면 만들어 재현하지 말고 ‘공식 배치도를 바탕으로 단순화한 공간 표현’으로 표시하세요.

‘주요 업체 둘러보기’와 ‘기술분야별 둘러보기’를 제공하되 실제 통로를 확인하지 못한 경우 탐방 순서만 안내하세요. 최단 도보경로라고 표시하지 마세요.

휴대폰은 탭·드래그·확대, PC는 클릭·휠로 사용할 수 있어야 합니다. 아바타·회원가입·게임 점수는 넣지 마세요. 입체보기가 지원되지 않아도 같은 업체를 2D에서 모두 탐색할 수 있게 만드세요.

업체 분석의 완성 기준

완성차, 핵심 하위체계, 소형 임무장비·부품에서 실제 참가·출품 근거가 있는 사례를 골라 상세 화면을 완성하세요. 예시만 만든 상태를 전체 조사 완료로 보고하지 마세요.

각 업체는 아래 내용으로 구성합니다.

1. 이 업체를 봐야 하는 이유: 해당 제품·기술에 기반한 한 문장 판단.
2. 이번 전시에서 보여준 것: 실제 확인된 출품품목·구성·협업·변경점과 현장사진.
3. 차별점: 비교 대상과 비교 조건이 있는 설명. 자료가 없으면 비교 불가로 남김.
4. 개발 방향 해석: 관찰·발표 근거에서 어떻게 판단했는지 설명.
5. 당사 체계개발과의 연결: 적용 검토·경쟁 비교·협업 탐색 등의 구체적 가치와 확인할 조건. 이미 채택하거나 협력 중인 것처럼 쓰지 않음.
6. 후속 확인: 공개자료로 판단되지 않는 핵심 사항 2~3개.
7. 근거: 원문 사진·제품자료·카탈로그·출처.

첫 화면에는 판단 한 문장과 핵심 3개 항목을 보여주고 상세 분석은 자연스럽게 펼쳐 읽도록 하세요.

‘혁신적·차세대·통합 솔루션’ 같은 추상적 칭찬이나 업체명만 바꾼 반복 분석을 금지합니다. 분량을 늘리려고 근거 없는 문장을 만들지 마세요.

참가만 확인된 기업도 기본정보와 업무 관련성은 읽을 수 있게 하되, 실제 전시품목이 미확인인 점을 짧게 구분하세요. 제조사 발표를 독립 검증된 성능으로 바꾸지 마세요.
