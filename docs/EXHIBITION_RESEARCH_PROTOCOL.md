# 전시회 공통 조사 절차

기준일: 2026-11-12 (Asia/Seoul). 적용: 4단계 서울 ADEX 2025, 5단계 Eurosatory 2026, 6단계 DSEI 2025, 7단계 IDEX 2025, 8단계 SAHA 2026. 4단계 수신 원문은 `docs/EXECUTIVE_V2_STAGE_4.md`. 이 절차는 이후 회차에도 그대로 적용하며, 아직 수신하지 않은 단계별 상세 지시를 대신하지 않습니다.

## 공통 조사 절차 — 사용자 원문

1. 해당 회차의 공식 명단 전체를 후보로 검토하고 관련/검토중/제외 사유를 기록하세요. 이미 끝난 업체는 새 근거가 있을 때만 갱신하세요.
2. 관련 기업의 회사명·국가·부스·업무 연결성을 채우고, 실제 확인된 모든 관련 출품품목을 제품별로 등록하세요. 회사의 일반 카탈로그는 배경자료로 구분하세요.
3. 제조사·주최사 자료뿐 아니라 현장 취재·촬영자가 공개한 사진도 조사하세요. 사진별 행사·연도·업체·제품·촬영자·원문을 확인하고, 사용 가능한 방식으로 표시하세요. 다른 행사 사진과 일반 홍보사진으로 현장사진을 대체하지 마세요.
4. 대표제품 하나만 남기지 말고 작은 임무장비·부품까지 찾아 연결하세요. 제품 사진이 부족하면 검증된 제품자료로 보완하되 자료의 성격을 표시하세요.
5. 업체별 판단·전시 특징·차별점·전략 해석·당사 관련성·후속 확인을 근거에 맞게 작성하세요. 자료 부족 기업도 목록에서 빠뜨리지 말고 확인된 범위까지만 작성하세요.
6. 확인된 부스만 지도에 연결하고 공동관·계열사·대리점 관계를 검토하세요.
7. 이번 묶음의 화면, 출처, 사진 연결과 집계 수를 확인한 뒤 저장·커밋하세요.

## 원장과 판단 기록

- 전체 후보: 해당 회차의 공식 디렉터리·가이드·배치도·국가관 원문을 확보하고 페이지/알파벳/분류/실내외 누락 범위를 기록합니다. 회차 변경·로그인·불완전 자료는 별도 잔여 상태입니다. 명칭 후보와 확인된 법인을 구분합니다.
- `data/v2/collection/{eventId}.json`은 원문 명단과 접근·누락 원장입니다. `data/v2/research/{eventId}/`는 검증한 묶음과 업체별 관련/검토중/제외 이유·출품·분석·사진을 저장합니다. 생성물만 수정하지 않습니다.
- 관련성, 참가 확인, 실제 제품 출품, 분석 상태는 별도 필드입니다. 조사에 착수하지 않은 기업을 자료부족으로 보고하지 않습니다. 자료부족은 실제 조사 후 확인하지 못한 범위와 다음 확인점을 남긴 기업입니다.
- 국가·법인·공동관·대리점 관계는 출처를 연결합니다. 부스번호와 좌표는 별도입니다. 번호만 확인되면 목록에 표시하고, 원문 도형 대조를 마치기 전 지도 좌표를 만들지 않습니다.
- 제품별 모델·품목을 등록합니다. 이름이 확인되지 않은 실물은 관찰 범위로 남기고, 한 사진에서 개별 품목 수를 만들어 세지 않습니다. 묶음 명칭과 개별 모델을 중복하여 새 제품 수로 세지 않습니다.
- 출품 근거는 현장 사진/현장 취재/업체의 행사 발표/배경자료로 구별합니다. 사전 출품 예고는 실제 현장 확인으로 승격하지 않습니다. 일반 카탈로그는 배경자료이며 해당 회차 현장사진 수에 포함하지 않습니다.
- 3단계 업체 화면의 판단 한 문장, 핵심 3항목, 전시 특징, 조건부 차별점, 전략 해석, 당사 연결, 후속 확인 2~3개와 근거 구조를 재사용합니다. 성능 비교조건이 없으면 비교 불가를 명시합니다.
- 핵심 주장 1차 원문 확인 후 독립 원문/사진 또는 원문 세부 대조로 2차 검수합니다. 단일 출처·재전재는 독립검증으로 세지 않습니다. 출처 수와 독립 원천 수를 혼동하지 않습니다.
- 사진마다 행사·연도·업체·제품(미식별이면 그대로)·촬영자 또는 제공기관·날짜·원문·이용조건을 기록합니다. 촬영자 미기재와 제공기관을 구분합니다. 권리 미확인은 원문 링크로 연결하고 복제·임베드 허가를 추정하지 않습니다. 사진을 볼 수 없으면 사진 확인 완료로 세지 않습니다.
- 완료 업체는 새 근거/정정이 있을 때만 내용 갱신합니다. 기존 분석을 정식 원장에 연결하는 작업은 새 업체/새 사진 증가로 계산하지 않습니다.

## 실행 단위와 종료 조건

약 10~20개 업체로 시작하되 자료량에 따라 단순 분류는 확대, 심층조사는 축소합니다. 막힌 기업은 정확한 사유와 다음 원문을 기록하고 다른 기업을 이어갑니다. 검증한 묶음마다 화면·출처·사진 연결·집계 검증 후 원장, STATUS의 `work`, HANDOFF를 함께 저장·커밋하고 원격 SHA를 확인합니다. 공개 배포는 기존 단계 제한을 따릅니다.

전체 모집단 미확보 시 전체 완료율을 계산하지 않습니다. 묶음 완료와 행사 전체 완료를 구별하고, 행사 단계의 종료에는 공식 모집단 대조 및 관련성 검토 범위·제품/사진/분석 잔여를 명시합니다.

종료 보고 필수: 이번 추가/보완 업체, 신규/세분화 제품, 신규 현장사진(화면 표시/원문 연결 구분), 누적 후보/관련/분석완료/자료부족/미착수, 제외·검토중, 지도 연결 범위, 다음 업체/원문 시작점, 단계 완료 여부와 계속 조사 필요 여부. 이 숫자는 마지막 빌드의 실제 원장에서 다시 계산합니다.
