## 일반 참관객 촬영 자료

[Maquettistes Montpellier의 1부 앨범](https://www.flickr.com/photos/139651532@N04/sets/72177720334276981)은 조사 시점 615장·영상 2개를 표시한다. **이는 원문 앨범 수량이며 개별 분석·수집 완료 수량이 아니다.** 첫 페이지에서 실제 차량 식별과 촬영일이 확인된 15장을 선별했다. 사진별 공개 공유 `canShare:true`와 Flickr oEmbed 응답을 확인했다. 각 응답에는 사진 URL·작성자·크기·HTML과 `All Rights Reserved`가 포함된다.

- [Flickr 공식 외부 표시 안내](https://www.flickrhelp.com/hc/en-us/articles/24282601008404-Embed-your-Flickr-content)는 이미지 표시 시 Flickr 원문 링크를 요구한다.
- 모든 사진은 `provider-embed`로 기록한다. 원본을 GitHub로 복제하지 않는다. 원저작권 표기를 CC나 퍼블릭도메인으로 바꾸지 않는다.
- `embedEvidenceUrl`은 각 사진의 검증된 oEmbed 요청 주소이며, `embedImageUrl`은 그 응답이 제공한 사진 URL이다. `embedHtml`도 기록했다.
- 최초 앨범 로고·영상·장비명 식별이 불완전한 흰색 위장 차량 6장은 제외했다. 수량을 늘리려고 모호한 장비를 합치지 않았다.

## 제조사 실제 행사 사진

- [기아 전시 보도](https://www.hyundaimotorgroup.com/ko/news/kia-eurosatory-2026-defense-exhibition): 실물 타스만·KLTV와 중·대형 모형을 구분한다. 사진 3장은 보도문 캡션 및 실제 부스 배경을 확인했다.

- [현대위아 전시 보도](https://www.hyundaimotorgroup.com/ko/news/hyundai-wia-eurosatory-2026-first-participation): 기존 파일 3장의 실제 촬영 행사가 이 행사임을 다시 확인했다. ADEX의 참고사진 대신 Eurosatory 본행사 사진으로 분류한다.
- 세 페이지 하단의 뉴스룸 이미지 사용 안내를 확인했다. 제공받은 일부 이미지 예외 조항이 있으므로 각 사진의 제3자 제한 표시가 없는지도 확인했다. 원저작자·출처를 유지한다.
- 새 이미지 4장은 긴 변 1,800px 이하로 축소하고 JPEG 압축만 적용했다. 자르기·합성·형상 수정 없음. 해상도·SHA-256은 JSON에 기록했다.
