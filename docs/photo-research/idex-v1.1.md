# IDEX 2025 실제 현장사진 수집 · v1.1

- 수집일: 2026-11-11
- 대상: 2025-02-17~21, 아부다비 ADNEC의 지상장비 실물 전시
- 장비군 8개, 원본사진 14장: 신규 저장 12장 + 기존 저장 재사용 2장
- 보고 권장사진 12장. HAVOC 같은 방향 연속촬영 2장은 `reportRecommended:false`로 구분했습니다.
- 모든 파일은 관람객·독립 사진가의 실제 행사사진으로 Commons 개별 파일의 CC BY 4.0을 확인했습니다. 공식 홍보사진은 이번 묶음에 추가하지 않았습니다.
- 저장본 합계 약 3.25 MB. 신규 파일은 EXIF 방향 보정·긴 변 최대 1800px·WebP 변환만 수행했습니다. 자르기·합성·형상 수정 없음.
- 외부 망에서 원본 다운로드 제한이 있어 일반 브라우저의 파일 다운로드 기능으로 원본을 수신했습니다. 접근 제한 우회나 권한 변경은 하지 않았습니다.

## 검증

1. 개별 Commons 설명·촬영일·행사 분류와 제조사 IDEX 2025 발표를 대조했습니다.
2. 수신 파일의 형식·크기·SHA256을 확인하고 14개 사진을 시각 검수했습니다. 부스·명패·장비 형상과 설명이 부합했습니다.
