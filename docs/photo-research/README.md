# 사진 탐색 기록

2026-11-10 Wikimedia Commons API에서 수집한 파일 제목·출처·저작자·라이선스 탐색 기록입니다. `selectedAssetId`가 있는 항목만 앱에 포함했습니다. 검색 결과에는 동음이의어·다른 장비·중복 크롭 등 제외 후보도 있습니다. 후보의 존재는 대상 장비나 전시회 관련성을 확인했다는 뜻이 아닙니다.

최종 사용 목록은 `../../data/photos.json`, 재사용 안내는 `../PHOTO_SOURCES.md`입니다. 원본 사진 설명의 장문 복제를 피하기 위해 탐색 기록에는 권리·출처 확인에 필요한 필드만 보관했습니다. 사진의 공개 이용조건은 Commons 파일 페이지의 표기를 기준으로 기록했으며, 원래 권리자의 별도 허락을 받아 새로 공개한 자료가 아닙니다.

제외 사례: K2PL 언론 제공 이미지(원출처의 자유 이용조건 미확인), THeMIS 크기 비교 그래픽(사진 아님), 전경 인원에 가려진 K808 사진, 중복 크롭, 장비와 무관한 동음이의어 검색 결과. 일부 Commons 파일 요청은 HTTP 429로 제한되었습니다. 대기 후 필요한 일부만 재시도했고, 재시도하지 않은 COBRA II·기존 PARS 후보는 저장하지 않았습니다.
