## 오류를 차단하는 검사

- 2027 출처/지도와 2025 행사 연결, 행사/회사/제품이 다른 출품 근거를 빌린 심층분석 완료를 거부합니다.
- 부분명단·미완료 페이지·모집단 대조 근거 없이 전체 완료율을 계산하는 오류를 거부합니다.
- 동일 원문의 재전재를 독립 검증으로 세지 않습니다. 출처 계보를 검토하지 않은 복수 URL도 독립 검증 완료가 아닙니다.
- 범위를 벗어난 도형, 검토 기록 없는 검증 좌표, 크기를 모르는 지도에서의 도형, 사용 허가 없는 원본 로컬 배포를 거부합니다.
- PEI의 원장 번호와 지도 영역을 같은 부스 개체로 연결합니다. 지도 region ID는 별도 보존합니다. ADEX 미해결 복합 명칭 8개는 업체 후보 수에서 제외합니다.
- public 데이터에는 수집 페이지·누락 목록·작업 큐·관련성 판정 업무·완료 집계를 넣지 않습니다. 출처·권리·원문/분석의 중요한 해석 조건은 유지합니다.

## 남은 범위와 완료 판단

2단계는 ‘공통 구조·이전·5개 회차 확보 상태/범위·ADEX 구현용 검증 부스’ 준비를 기준으로 종료합니다. 전체 참가사 수집·관련성 판정·심층분석의 완료를 뜻하지 않습니다. 원장 `queues` 17개가 행사별 4~8단계에 연결됩니다. 아직 받지 않은 해당 단계 상세 지시를 대신 작성하지 않았습니다.

ADEX 원본 지도 배경의 재호스팅/임베드 사용권, 전체 디렉터리와 214개 전사 확인, Eurosatory 전체 카탈로그, IDEX 전체 공식 원장, 기타 회차 부스 지도는 남아 있습니다. 3단계는 이 제한을 지키며 지도·업체 화면 구현으로 진행할 수 있습니다. 상세 3단계 지시는 미수신입니다. 최종 UI 기능 제거·모든 사진 로딩·모바일·전체 PDF·배포는 수행하지 않았습니다.
