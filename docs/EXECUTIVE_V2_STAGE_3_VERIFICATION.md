## 구현 범위

- ADEX 공식 PDF와 주최사 PNG를 대조한 32개 사전 배치 영역·35개 연결 명칭. 원격 PNG는 328,639 bytes이며 배포 assets로 복제하지 않습니다.
- 2D·상징적 낮은 블록 입체보기, 확대/축소/드래그/휠/키보드, 홀 7~10 전환, 검색·분류·공동부스·업체 패널, 주요 업체·기술분야 탐방 순서. 실측 높이·가짜 통로·미확인 좌표를 만들지 않았습니다.
- URL에 회차·검색·분류·홀·업체·부스·시점·사진·비교 선택·탐방 순서를 보관합니다. 브라우저 저장소를 사용하지 않습니다.
- 현대로템·기아·STX엔진·현대위아·PEI의 5개 실제 근거 사례. 7개 상세 항목, 한 문장 판단·3개 요점, 원문 조건, 실제/귀속 발표/해석의 구별을 유지합니다. 전체 모집단 완료가 아닙니다.
- 5개 회차 데이터 분할. 검증 지도가 없는 회차는 목록으로 연결합니다. 일반 행사 안내도를 부스 배치도로 승격하지 않습니다.
- 사진 확대·추가 각도·다른 회차 참고사진 분리, 원문 카탈로그, 업체 비교, 인쇄용 업체/비교/전체 사례 보고서. 개인 업로드·편집·백업/복원·보관함·조사 관리 모듈은 최종 빌드에서 제외했습니다.

## 확인하지 못한 범위

- **실제 PDF 저장 파일·페이지 나눔:** 검증용 관리 Chromium의 Print 메뉴가 비활성화되어 버튼과 Ctrl+P로 인쇄 대화상자를 열 수 없었습니다. 인쇄 내용 준비·비교표·출처 보존 검사는 통과했지만 파일 저장 성공이나 페이지 검수를 주장하지 않습니다. 정책을 변경하지 않았습니다.
- **실제 휴대폰:** 좁은 뷰포트 검증과 실제 PointerEvent 핸들러 회귀시험(탭, 드래그, 두 손가락 핀치, 취소, 휠, 키보드)은 수행했습니다. 실제 Android/iOS 터치·적중 판정은 미검증입니다. DevTools 기기 에뮬레이션도 관리 정책으로 사용할 수 없었습니다.
- 모든 사진 원문의 실시간 접근·전체 회차 심층분석·큰 전시장 실기기 성능 벤치마크는 완료하지 않았습니다. ADEX 행사는 524 KB 샤드와 329 KB 배경만 먼저 가져오며, 다른 회차와 사진은 필요한 시점에 로딩합니다.
- 기존 사용자 localStorage/IndexedDB는 읽거나 쓰거나 지우지 않았습니다. 공개 배포·main 변경은 하지 않았습니다.

기계 판독 기록: [CHECKS.json](evidence/EXECUTIVE_V2_STAGE_3_CHECKS.json). 임시 모바일 QA HTML은 `tests/fixtures`에만 보존하고 최종 `dist`에는 포함하지 않았습니다. 원격 CI/ref와 로컬 tree 일치도 확인했습니다.
