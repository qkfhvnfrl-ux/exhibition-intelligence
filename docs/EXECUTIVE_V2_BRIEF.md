# FIELDNOTE v2 — 상무 보고용 공통 기준

기준일: 2026-11-12 (Asia/Seoul). 사용자 지시 원문: [1단계](EXECUTIVE_V2_STAGE_1.md).

기존 저장소 `qkfhvnfrl-ux/exhibition-intelligence` 및 공개 주소 `https://qkfhvnfrl-ux.github.io/exhibition-intelligence/`를 유지합니다. 이 문서는 공통 기준과 받은 단계 지시의 연결점입니다. 진행 사실은 [STATUS](EXECUTIVE_V2_STATUS.json), 재시작은 [HANDOFF](EXECUTIVE_V2_HANDOFF.md), 기존 기능·데이터 조사 결과는 [AUDIT](EXECUTIVE_V2_AUDIT.md)를 기준으로 합니다.

## 완성할 제품

상무가 첫 화면의 실제 전시장 배치도를 둘러보고 부스를 누르면 해당 업체의 현장사진·출품장비·분석을 바로 읽는 웹앱입니다. 업체별·전시회별 개발 방향과 검토 가치를 간결하게 전달합니다. 지도·사진·분석의 완성도와 정보량을 우선하며 기업 수를 임의로 제한하지 않습니다.

대상 회차: 서울 ADEX 2025, Eurosatory 2026, DSEI 2025, IDEX 2025, SAHA 2026. 다른 회차의 사진·일반제품 정보를 해당 회차 실제 출품자료로 바꾸지 않습니다.

## 조사 범위

현대로템 차륜형장갑차 체계개발과 조금이라도 관련된 참가기업을 포함합니다. 규모·인지도·사진 유무는 제외 기준이 아닙니다.

- 완성차, 동력전달, 차축·현수·조향·제동, 타이어·CTIS
- 냉각·공조, 전력·배터리·배선, 소화·방호
- 통신·항법·광학·상황인식, 임무컴퓨터, 원격·무인체계
- 좌석·내장·지휘소·의무후송 모듈
- 커넥터·밸브·펌프·실링
- 정비·시험·진단·시뮬레이션·제조기술

## 화면 및 정보 기준

주 메뉴는 **전시장 탐색 / 업체·장비 / 핵심 보고** 세 개입니다. 검색·비교·PDF는 필요한 화면에 붙입니다.

개인 사진 등록, 메모·주석 편집, 백업·복원, 과거 보관함, 개발 진행률·디버그와 관련 관리 기능은 일반 화면과 최종 배포 기능에서 제거합니다. 기존 원본·사용자 기록은 보존하며 브라우저 저장소를 지우지 않습니다. 보존용 관리자 화면은 새로 만들지 않습니다.

출처·자료 기준일·중요한 해석 조건은 작고 명확하게 유지합니다. 사실/해석/확인 같은 큰 관리 패널은 반복하지 않습니다. 실제 제품·부스 사진과 자료를 사용하고 형상·성능·전시 여부·부스 위치를 만들지 않습니다. 사진이 없다는 이유로 업체를 빼거나 생성 이미지로 대체하지 않습니다.

핵심 주장은 원문과 다른 자료를 재대조합니다. 하나뿐인 근거는 단일 근거로 표시합니다. 같은 보도자료의 재전재는 독립 검증으로 세지 않습니다. 기존 데이터의 URL 수나 기존 자동검사 통과를 내용의 독립 검증으로 간주하지 않습니다.

## unslop 적용

[고정 버전·원문·적용 기록](EXECUTIVE_V2_UNSLOP.md)을 읽습니다. 순서는 **간격 → 색 → 아이콘 → 문구 → 글꼴 → 배치 → 세부요소 → 사진 → 움직임**입니다. 한글 가독성·많은 실사진·정확한 수치·의미 있는 상태색을 우선합니다. 사용자가 삭제와 구조 변경을 명시했으므로 원본 스킬의 일반적인 기능/섹션 보존 원칙으로 이를 막지 않습니다. 디자인 방향 재승인은 필요하지 않습니다.

## 실행 원칙

실제 소스·데이터를 수정하고 검증한 묶음마다 저장·커밋합니다. 작업 여유가 있으면 여러 묶음을 이어서 수행하고 한 업체나 자료의 막힘은 별도로 기록합니다. 기존 배포 교체 전에는 개발 브랜치·미리보기에서 검증합니다. 단계 종료 전에 코드·데이터·상태 문서를 커밋하고 GitHub 원격 반영을 재확인합니다. 원격 실패 시 미반영 범위와 복구 산출물을 남깁니다. 상세 작업 규칙은 [AGENTS.md](../AGENTS.md)입니다.

1단계에서는 조사·보존·작업 기반과 배포 가드를 완료합니다. 삭제 대상과 3개 메뉴는 확정했으며 화면·기능 제거의 실제 구현은 3단계 작업입니다. 1단계 완료를 v2 UI·전수 조사·배포 완료로 표현하지 않습니다.
