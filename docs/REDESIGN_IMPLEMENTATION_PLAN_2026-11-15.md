# 승인된 개편 구현 계획

기준일: 2026-11-15. 기준 작업 커밋 a21b781.

## 입력·승인·현재 상태

사용자가 A단계의 ‘큰 지도 → 별도 업체 메인 → 장비별 설명 → 16:9 종합보고(모바일 세로)’ 구조로 본 구현을 승인했다. 첫 공개 반영 대상은 기존 `/preview/`이며 실제 배포는 완성본 검토 뒤 진행한다. 현재 정적 앱과 5개 회차·전체 업체 원장은 유지한다. A단계 초안은 완료했고 3사 장비 근거 보강 중이다. 이전 승인을 다시 묻지 않는다.

## 목표

1. 기존 지도와 검색을 유지하면서 업체 화면을 독립 화면으로 연결한다. product 딥링크와 지도 카메라 복귀를 지원한다.
2. 기존 실제 사진을 장비별로 연결하고 다섯 설명 항목·출품형상·공식 발표/관찰 추론·자료 한계를 기본 화면에 표시한다.
3. 같은 전시회 직전 회차 비교를 포함하는 16:9 종합보고와 인쇄/PDF를 구현한다. 확인된 사례의 해석을 전체 행사 통계로 확대하지 않는다.
4. 공개 내부 업무 연결 내용은 원천·생성기·검증·문서·배포 데이터에서 정리한다. Git 이력과 사용자 저장소는 보존한다.
5. 전체 업체 접근성과 나머지 4개 회차에 같은 화면 구조를 적용한다. 자료 미확보는 정확히 표시한다.

## 수정 파일과 분담

- index.html, src/v2/app.js·app.css·state.js: 화면 흐름, 지도/검색, URL 상태, 접근성.
- src/v2/details.js·details.css: 업체 메인, 장비 갤러리/설명, 기존 사진 확대·비교·상세 인쇄 유지.
- src/v2/report.js·report.css: 종합 한장 및 PDF.
- data/v2/editorial, data/v2/research 및 기존 공개 원천, scripts/*v2*.mjs: 장비 근거 보강, 공개 내용 정리, 생성 계약.
- tests: URL/지도 복귀/내용 연결/인쇄/공개 데이터 회귀 및 Windows 검증 이식성.
- docs 및 프로젝트 운영 6종: 승인·상태·검증·자료 한계 기록.

## 영향 범위·리스크

정적 ES module·현재 ID·원장·지도 좌표·기존 URL 호환을 유지한다. 신규 프레임워크/라이브러리/백엔드/3D/PPTX 도입 없음. 장비 설명은 기존 제품에 선택적 근거 필드를 추가하는 방식으로 연결한다. 미확보 사진, 혼합 전시형상, 단일 제조사 발표, 현재 카탈로그의 시점 차이를 숨기지 않는다. 문서 정리는 내부 원문 복제 없이 진행하고 기존 이력을 재작성하지 않는다. 공개 원천의 정리는 이번 전달 프롬프트에 명시 승인된 범위다.

## 검증

Build → Test/check → 가능한 lint(별도 스크립트 없음) → 실제 브라우저. 장비/출처 참조 무결성, 5회차/업체 수 보존, 금지 필드/문구/첨부 감사, 사진 로딩, 공동부스, 검색, 새로고침/뒤로가기/장비 링크/지도 카메라, 1440px·390px 가독성, 하위 preview 경로, 실제 저장 PDF의 한 장·한글·사진·잘림을 확인한다. 실패는 증거와 함께 수정 후 재검증한다. 배포는 이 검증과 완성본 검토 후 `/preview/`만 진행한다.
