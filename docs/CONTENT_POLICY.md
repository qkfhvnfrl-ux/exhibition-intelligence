# 공개자료 검토 기준

1. 업체 참가와 특정 장비 전시는 별도의 사실이다. 장비명과 전시회가 함께 확인되는 원문을 연결한다.
2. 사진은 원출처·저작자·라이선스·실제 계열형·참고/현장 구분을 갖는다. 현장사진을 확보하지 못한 경우 다른 회차 사진을 현재 회차로 표시하지 않는다.
3. 기본형 제원을 개조형 제원으로 전용하지 않는다. 공식 공개값도 시험 검증값과 구분한다.
4. 현재 보고 화면은 장비별 1~2문장의 개발전략 해석과 짧은 전시 특징으로 요약한다. 근거 원문은 펼쳐볼 수 있게 연결하며 분석 의견임을 표시한다. 근거 없는 순위·임의 총점·사진 추정의 확정값화를 금지한다. 이전 사실/해석/확인 삼분류는 기존 작업 보존용 보관함에만 남긴다.
5. 직전 회차와 비교할 양쪽 근거가 없으면 변화 판단을 미확인으로 표시한다.
6. 수록 장비의 수·유형 분포는 조사 표본이다. 전시회 전체 비중 또는 시장점유율로 표현하지 않는다.
7. 소스에 포함된 인원별 업무·사내 보고·회의녹음은 공개 저장소에 저장하지 않는다.
8. 항공·해양은 현재 데이터셋 범위 밖이다. 카테고리 구조를 확장 가능하게 유지한다.
9. v1.1 보고 범위는 2024-11-11~2026-11-11에 열린 5개 최신 회차이다. ADEX 2025, DSEI 2025, IDEX 2025, Eurosatory 2026, SAHA 2026의 실제 현장자료만 사용한다. 다른 행사·훈련·기존형 사진은 새 보고 화면에서 제외한다.
10. 일반 촬영자의 사진도 행사·날짜·장비를 확인하여 수집한다. 재사용 허가 사진은 출처와 조건을 유지하고, 플랫폼이 허용한 외부 표시는 원본 링크·저작자를 유지한다. 재게시 조건이 확인되지 않은 사진은 원문 링크로만 제공한다.
11. 앱 표시 사진과 원문 링크 자료를 별도 집계한다. 앨범 전체 장수는 조사한 장수로 합산하지 않으며 동일 원본의 중복 사용도 사진 수를 늘리지 않는다.

## 검토 절차
자료 수집 → 장비/형상/행사 대조 → 출처와 제원 대조 → 사실/의견 분리 → 데이터 검증 → UI/사진/출력 검토 → 버전 커밋.
