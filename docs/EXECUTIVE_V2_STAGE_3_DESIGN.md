# FIELDNOTE v2 3단계 화면 적용 기록

확인일: 2026-11-12 (Asia/Seoul). 적용 원본은 unslop by Damir Sokolovsky, CC BY 4.0, 커밋 `97daa3eb365670ea3f87ed85356cbfcee18105a5`입니다. 원본/라이선스는 [기존 기록](EXECUTIVE_V2_UNSLOP.md)에 연결하며 수정하지 않았습니다. 설치본 SKILL.md와 signs/tokens/visuals/refs/effects reference를 읽었습니다. 생성 이미지나 스킬 예시 이미지를 전시 사진으로 사용하지 않았습니다.

기존 1.1 화면을 브라우저로 확인한 뒤, 사용자가 확정한 ‘실제 지도·실사진·짧은 기술 판단’ 방향으로 새 런타임을 구성했습니다. 기존 기능 삭제와 구조 변경은 요청 범위이며 별도 디자인 승인을 가정하지 않았습니다.

| 순서 | 실제 적용 및 확인 |
| --- | --- |
| 1 간격 | 4px 배수의 여백·버튼·행 간격. 지도/패널 분리, 같은 종류 컨트롤 높이 정렬. 좁은 화면에서 필터 두 줄과 전체폭 검색으로 전환 |
| 2 색 | 흰색·회색 표면, 녹색은 선택 부스·현재 메뉴, 황토색은 검색에 맞는 부스. 원본 지도 색은 그대로 유지 |
| 3 아이콘 | 검색·위치·확대·닫기·인쇄에 얇은 SVG와 텍스트 레이블. 이모지/의미 없는 배지 제외 |
| 4 문구 | 3개 주 메뉴, 실제 품목 중심 한 문장과 3개 요점. 사전 배치도·번호 상충·일반자료 조건을 짧게 표기. 빈 지도에는 검증된 좌표가 없다는 이유와 업체 목록 연결만 표시 |
| 5 글꼴 | IBM Plex Sans KR, 한국어 본문 16px 이상, 세부 분석 16~20px, 읽을 수 있는 행간. 수량·좌표 등 수치에 tabular numerals |
| 6 배치 | 첫 화면 중앙 지도, 우측 선택 업체. 좁은 화면은 지도 다음 상세. 상세 첫 부분은 판단·3항목, 대표 현장사진과 추가 각도, 펼쳐 읽는 분석. 다른 회차 참고사진은 별도 접기 영역 |
| 7 세부요소 | 공동부스 선택, 위치 미확인 목록, 사진 원문·PDF 새 창, 상태 URL·뒤로가기, 출처 조건, 지연 로딩 실패 안내, 키보드 포커스. 중복 카탈로그 탭·초점 이동 기록 문제를 실제 검토에서 수정 |
| 8 사진 | 기존 사진·각도 보존. object-fit:contain과 확대 보기로 형상·비율 유지. ADEX 42개 사진 개체와 원문 참조를 유지하고 권리 미확인 사진은 직접 복제하지 않음 |
| 9 움직임 | 부스 선택 때 280ms 시점 이동, 휠·드래그·핀치. reduced-motion 지원. 지속 애니메이션/아바타/게임 점수 없음. 2D와 입체보기는 같은 검증 좌표 사용 |

입체 블록의 높이는 모두 화면 식별을 위한 상징적 값입니다. 실제 부스 높이·외관·장비 배치로 설명하지 않습니다. WebGL 없이 SVG 투영으로 구현했고 2D에서도 같은 업체를 모두 선택할 수 있습니다. 홀 7·8의 확인되지 않은 분리 경계, 야외·층 좌표, 실제 통로 경로를 생성하지 않았습니다.
