# A단계 로컬 화면 초안

목표: 기존 지도·사진·원장을 이용해 지도 → 업체 메인 → 장비 → 한장 보고의 검토 가능한 화면 방향을 제시한다.

- 수정 파일: 이 review/ 폴더만. 기존 src/data/package/배포 기능은 수정하지 않는다.
- 영향: 별도 로컬 화면. 기존 서비스의 기능 제거·원장 변경·공개 배포 없음.
- 리스크: 공식 배치도 외부 이미지 로딩, 업체별 사진 결측, 기존 사진의 빈 productIds, 비교 회차 미조사.
- 검증: JS 문법 검사, 생성 데이터 내부 필드·파일 경로 검사, 부모 에이전트의 브라우저 화면 확인.
- 승인: 사용자 전달 문서 A.8의 로컬 화면 초안 제작 요청 범위. 실서비스 구현은 다음 검토 후 수행.

## 실행

저장소 루트에서 `npm run build` 후 `node review/build-review.mjs`를 실행한다. 기존 정적 서버의 root를 저장소로 지정해 `/review/`를 연다. 검토 명령: `node scripts/serve.mjs --root . --host 127.0.0.1 --port 4174`. 브라우저 주소: `http://127.0.0.1:4174/review/`. 최종 브라우저 증거는 verification.json과 screenshots/에 있다.

이 초안은 `scripts/build.mjs`의 배포 allowlist에 포함되지 않는다. 기존 지도 모듈만 읽기 전용 재사용하며 2D 화면만 제공한다. 개인 localStorage/IndexedDB를 읽거나 쓰지 않는다.

## 데이터 경계

review/data.json은 생성된 앱 데이터에서 명시적으로 허용한 공개용 필드만 추출한다. 내부 관련성 필드를 가져오지 않는다. 표본의 7개 현장사진은 기존 기록의 캡션과 형상 제한을 확인해 초안에 연결했으며, 새 출품/권리/원문 재검증을 완료했다는 뜻은 아니다. K2PL의 전면 가림, RCWS 분리 전시, 현대위아 부스 전경 미확보를 명시한다.

보고의 ADEX 2023 비교는 미검증 상태로 남긴다. 확인된 3사 사례의 관찰을 행사 전체 통계나 증가·감소로 해석하지 않는다. 인쇄/PDF 버튼은 이번 초안에 추가하지 않으며 기존 기능 활용 검토를 후속 구현 계획으로 남긴다.

## QA 후 문구 보정 계획

부모의 실제 화면 검토에 따라 비교 근거 없는 ‘확장’ 표현을 ‘다양한 구성’으로 바꾸고, AI 기반 RCWS의 사진 상태를 공동사진 확보/형식별 연결 보강으로 구분한다. 변경 범위는 초안 문구뿐이며 제품 원천과 사진 매핑의 추가 확인 필요 상태를 유지한다. 문법·문구 검사를 실행하고 부모가 새로고침해 확인한다.
